# WireForge — ハーネス配線図エディタ

学生フォーミュラEV向けの車両ハーネス配線図をブラウザで作成するツールです。サーバー不要で、GitHub Pages にそのまま置いて使えます。

**公開版: https://studentsofiwateformulateam.github.io/WireForge/**

## 使い方（ローカル）
ES Modules を使っているため、`index.html` をダブルクリックではなく簡易サーバー経由で開いてください。

```bash
python -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

## GitHub Pages で公開
1. このフォルダを GitHub リポジトリに push
2. リポジトリの Settings → Pages → Source: `Deploy from a branch`、Branch: `main` / `/ (root)`
3. 表示された URL を開く（ビルド作業は不要。`.nojekyll` を置いているので、ファイルはそのまま配信されます）

> **非公開リポジトリの場合**: GitHub Pages を非公開リポジトリから公開するには、GitHub Pro / Team など有料プラン（教育機関向けの無償枠を含む）が必要です。無料プランでは、リポジトリを公開にするか、ローカルで使ってください。

## 保存と PDF
- **自動保存**: 編集内容はブラウザ（localStorage）に自動保存され、次に開いた時に復元されます。ブラウザ・PC が変わると引き継がれないため、残す場合は「保存」でファイルにしてください。
- **保存 / 開く**: プロジェクトは `○○.harness.json` として保存します。画面にドロップしても開けます。
- **PDF 出力**: 「PDF出力」→「印刷ダイアログを開く」→ 送信先で「PDF に保存」。全ページが 1 つの PDF になり、用紙サイズ・向きはページごとの設定が使われます（Chrome / Edge 推奨）。

## 図面チェック
ツールバーの「✓ 図面チェック」で、図面の問題点を一覧表示します（開いたまま編集すると自動で更新されます）。項目をクリックすると該当ページ・部品を選択します。

| 区分 | 内容 |
|---|---|
| ⛔ エラー | 部品データが無いコネクタ、接続先のコネクタ・ピンが無い配線、基準配線が無いチューブ など（図面に描画されない） |
| ⚠ 警告 | 1 ピンに複数本の配線、同じページ内のコネクタ名の重複、つながっていない配線に同じ配線名、図枠からのはみ出し・表題欄との重なり、チューブ番号の重複 |
| ℹ 未入力 | 配線名・配線長さ・チューブ長さの未入力、ラベル同士の重なり |

- ファイルを開くときは、壊れたデータ（不正な値・重複した ID・接続先の無い配線など）を自動で修復し、修復内容を表示します。元のファイルは変更しません。
- 右パネル（何も選択していない状態）の「ラベルを自動配置」で、配線・チューブのラベルを重ならない位置へ並べ直せます。
- 操作方法の一覧はツールバーの「?」（または `?` キー）で表示できます。

## テスト
簡易サーバーを起動して `http://localhost:8000/tests/` を開くと、自動テスト（約 150 項目）が実行されます。
テストはブラウザの自動保存データを消去するため、localhost 以外（公開サイト）では実行されないようにしています。

## 構成
```
index.html
css/app.css
js/
  main.js                  起動処理
  core/    model.js        図面データ（JSON）のスキーマ・生成・互換変換
           store.js        状態管理・Undo/Redo
           geometry.js     座標変換・形状計算
           wires.js        配線の経路・ネット計算
           tubes.js        チューブの位置計算（基準配線上の範囲 t0〜t1）
           io.js           JSON 保存・読み込み・自動保存
           check.js        図面チェック（整合性・記入漏れ）
  catalog/connectors/      コネクタ部品データ（断面図形状・ピン配置）
  catalog/wireSpecs.js     配線の種類・太さ・色
  catalog/tubeSpecs.js     コルゲートチューブのサイズ・色
  render/                  SVG 描画（画面と PDF で共通）
  editor/                  キャンバス操作・編集コマンド・PDF 出力(print.js)・ラベル自動配置(labelLayout.js)
  ui/                      ツールバー・各パネル・ダイアログ
tests/                     自動テスト（localhost でのみ実行）
docs/datasheet-notes.md    断面図・ピン配置の根拠
```
- **部品データ**（`catalog/`）と**図面データ**（プロジェクト JSON）は分離しています。プロジェクトには部品の `partId` と配置情報のみを保存します。
- `Datasheet/` はメーカーの著作物のため `.gitignore` で除外しています。
